SOLMARINA is an open-world crime game in the spirit of GTA 6, playable in a desktop browser from static files: a sun-soaked coastal city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted level with police who chase you, five story missions from the fixer Mara Voss, combat, a HUD with a minimap, and a save. Built with three.js (vendored) and plain ES modules — no build step, no network requests. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

WASD move · Shift run · E enter / exit car · F punch · Click shoot · R reload · Drag mouse to orbit the camera · P pause · M mute

## Story

Jules Maro steps off a boat in Solmarina with $150 and no friends. Mara Voss, who runs the marina, has five jobs: steal wheels, pick up Lennox, survive the heat, run a package, and rob the Solmarina Trust. Finish them all and the city is yours.
